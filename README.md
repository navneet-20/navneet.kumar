# Navneet Kumar Portfolio

Static portfolio for https://navneet.webline.cloud/

## Structure
- `index.html` — homepage
- `css/style.css` — design system and responsive layout
- `js/main.js` — mobile menu, reveal animations, dynamic year
- `CV.pdf` — current resume (place your latest root CV here)
- `CNAME` — GitHub Pages custom domain
- `robots.txt` / `sitemap.xml` — basic SEO

## Deploy
Push the files to the `main` branch of the existing `navneet-20/navneet.kumar` repository. Keep the existing `CV.pdf` in the repository root.
